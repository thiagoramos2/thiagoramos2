Experiência no desenvolvimento, integração, manutenção e suporte de soluções de telecomunicações, telefonia IP e comunicação empresarial.

- **Asterisk:** configuração, administração, manutenção e desenvolvimento de funcionalidades para PABX IP e plataformas de telefonia.

- **STFC:** integrações relacionadas a serviços de telefonia fixa comutada.
- **Portabilidade numérica e billing:** integração com processos e sistemas de telecomunicações.
